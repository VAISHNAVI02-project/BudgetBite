# BudgetBite 🍔

**BudgetBite** is a budget-based food ordering website that helps users find food items according to their available budget.

## 🚀 Features

- Browse food items based on budget.
- Add food items to the cart.
- Checkout and place orders.
- Track order status.
- Admin dashboard to view orders and revenue.
- Admin can update order status.
- MySQL database integration.

## 🛠️ Technologies Used

- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Tools:** VS Code, Git, GitHub, XAMPP

## 💻 How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd BudgetBite
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Install Dependencies

Open separate terminals for the frontend and backend.

Backend:
```bash
cd backend
npm install
node server.js
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```

### 3. Database Setup

1. Start Apache and MySQL in XAMPP.
2. Open phpMyAdmin.
3. Create the database `budgetbite_db`.
4. Import or execute the project's database SQL script, if provided.
5. Configure database settings using environment variables if required.

### 4. Open the Website

Open the local URL displayed by Vite, usually:

`http://localhost:5173`

## 🎯 Project Objective

To make food ordering more convenient by helping users discover food options that fit their budget.
